# Shiny_Trust_Breach – Contractor_Onboarding_SOP

Contractor Onboarding SOP – Workforce Reinforcement

## Purpose

Ensure all third-party IT staff meet baseline technical + soft skills for escalation, IAM handling, and AI awareness.

## Scope

Applies to all offshore contractors, managed service providers, and vendor admins with system access.

## Procedure

- **Day 1–30:** Baseline onboarding → IAM, escalation protocols, communication expectations.

- **Day 90:** Reinforcement module → scenario-based SOC escalation & AI phishing drills.
- **Day 180:** Certification & re-evaluation → must pass technical + soft skill validation.
- **Ongoing:** Annual re-certification tied to vendor contract renewal.

## Enforcement

Failure = restricted access or termination of vendor contract.
